# RAG Server

AIアシスタントが回答する時に参照するデータをベクトル化して入れるRAGサーバ。
このディレクトリはモノレポのワークスペースの一つである。

## 技術スタック

- uv
- Python 3.13
- Chroma
- Ruff
- mypy

## コードスタイル

- Ruff (全ルールON)でチェック。
- mypy (strict)でチェック。
- ただし、現状ソースコードはない。

## コマンド

Workspaceのディレクトリではなくプロジェクトルートのディレクトリから実行。

- `make -C ./apps/rag-server start`: RAGサーバ（Chroma）起動。Chromaの不具合でシグナル送信で終了しないため、終了したい場合は人間に依頼すること。
